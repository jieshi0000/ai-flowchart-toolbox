# AI 生成流程图测试用例

## 1. 测试范围与依据

- 测试对象：AI 生成流程图后端 API、DiagramDocument 结构校验、任务/文档/导出/供应商服务，以及需求文档定义的工作台关键流程。
- 需求依据：[AI生成流程图需求文档](../需求文档/AI生成流程图需求文档.md)、[AI生成流程图设计方案](../设计文档/AI生成流程图设计方案.md)。
- 自动化依据：`backend/tests/unit/` 现有单元测试；集成测试依赖 `backend/tests/docker-compose.yml` 中的 PostgreSQL 与 Redis。
- 测试环境：Windows 11、Python 3.12、uv、Node.js/pnpm；服务地址以当前部署配置为准，性能阈值沿用需求文档。
