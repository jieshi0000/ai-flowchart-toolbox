# 导出字体

导出 Worker 固定使用以下随镜像分发的字体：

- `Inter/Inter-Regular.ttf` 与 `Inter/Inter-Bold.ttf`：Inter 项目，SIL Open Font License 1.1。
- `SourceHanSansSC/SourceHanSansSC-Regular.otf`：Adobe Source Han Sans SC，SIL Open Font License 1.1。

字体只用于流程图预览和导出，不接受用户上传字体。对应许可证文件保存在各自目录中；更新字体版本时须同步更新许可证和来源记录。

来源与校验：

- Inter：<https://github.com/rsms/inter>，SHA-256 分别为 `1B08E7FC267A5C7E1D614100F604B83E7E8A0BE241F0F288FAA2B3AC93A683BA`（Regular）和 `B37284B5701B6B168DFC770AA1A4AC492106422FD3BA76BC7641E37434E8019C`（Bold）。
- Source Han Sans SC：<https://github.com/adobe-fonts/source-han-sans> 的 `release/OTF/SimplifiedChinese/SourceHanSansSC-Regular.otf`，SHA-256 为 `F1D8611151880C6C336AABEAC4640EF434FA13CBFBF1FFE82D0A71B2A5637256`。
