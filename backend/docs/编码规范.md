# 编码规范

## 新增业务实体流程

1. 创建 SQLAlchemy Model（继承 `BaseDBModel`），放在 `models/`
2. 创建 Pydantic Schema（VO、CreateReq、UpdateReq），放在 `schemas/`（简单场景可省略）
3. 创建 Service 函数，放在 `services/`
4. 创建 API 路由，放在 `api/`
5. 在 `main.py` 中 `include_router`

## 目录结构约定

| 目录 | 放什么 | 说明 |
|------|--------|------|
| `main.py` | 应用组装入口 | lifespan / 中间件 / 路由挂载 |
| `core/` | 基础设施 | 配置、加解密、日志、DB 会话、Redis |
| `db/` | 迁移引擎 | 读项目根 `db/*.sql` 并执行（非运行时 Session） |
| `models/` | SQLAlchemy DB model | 映射数据库表 |
| `schemas/` | Pydantic 请求/响应 schema | 定义 API 结构（简单接口可省略，直接返回 dict） |
| `api/` | FastAPI 路由 | 参数校验，调用 service |
| `services/` | 业务逻辑函数 | 数据库操作 |
| `middleware/` / `exceptions/` | 横切 | 认证、CORS、统一异常 |

## Model / Schema 关系

- **Model**: SQLAlchemy ORM，字段名用 **snake_case**
- **Schema**: Pydantic，字段名也用 **snake_case**（默认 `APP__JSON_CAMEL_CASE=true`，JSON 输出自动转 camelCase）
- 简单场景：`DemoProductVO.model_validate(product)` 直接转换
- 复杂场景（字段名不同、需要计算）：手动映射

```python
# 简单场景
def to_vo(product: DemoProduct) -> DemoProductVO:
    return DemoProductVO.model_validate(product)

# 复杂场景
def to_vo(product: DemoProduct) -> DemoProductVO:
    return DemoProductVO(
        id=product.id,
        name=product.name,
        price=float(product.price),
        tag_names=",".join(product.tags) if product.tags else "",
    )
```

## 统一响应

所有 API 返回 `Result[T]`：

```python
from app.schemas.common import Result

@router.get("/get")
async def get_product(id: UUID, session: AsyncSession = Depends(get_session)):
    product = await get_product_by_id(session, id)
    if not product:
        raise BusinessException(code=404, message="商品不存在")
    return Result.success(data=to_vo(product))
```

## 参数校验

使用 Pydantic `Field` 验证，FastAPI 自动校验：

```python
class DemoProductCreateReq(BaseModel):
    name: str = Field(..., min_length=1, max_length=100, description="商品名称")
    price: float = Field(..., gt=0, description="价格")
```

## 单例模式

使用 `functools.lru_cache`：

```python
from functools import lru_cache
from app.core.config import Settings, resolve_env_files

@lru_cache
def get_settings() -> Settings:
    return Settings(_env_file=resolve_env_files())

@lru_cache
def get_engine():
    return create_async_engine(...)
```

## 数据库 Session

通过 FastAPI `Depends` 注入：

```python
from app.core.database import get_session

async def my_api(session: AsyncSession = Depends(get_session)):
    ...
```

## camelCase 输出

通过 `.env` 配置 `APP__JSON_CAMEL_CASE` 全局切换（默认 `true` / camelCase；设 `false` 则 snake_case），不需要在每个 Schema 中加 alias。详见接口设计规范。
