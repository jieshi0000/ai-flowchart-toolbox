# 测试规范

## 单元测试（强制）

所有新增业务代码必须编写单元测试：

- **Service 层**：测试业务逻辑，不强求 Mock 数据库
- **Schema 层**：验证 Pydantic 参数校验规则
- **异常处理**：验证异常抛出和错误码

### 验证要求

- 新增 Service 方法必须有对应测试用例
- 新增 Pydantic Schema 必须验证参数校验
- 核心业务逻辑（如分页计算、数据转换）必须覆盖

## 数据库测试（可选）

集成测试不强制，开发者可按需使用真实测试数据库：

```bash
# 启动测试数据库
cd tests && docker compose up -d
```

数据库连接配置见 `tests/docker-compose.yml`。

## 接口测试（按需）

端到端接口测试不强制，开发者可按需进行：

- 使用 `.http` 脚本文件或 Swagger UI 手动验证
- 接口脚本放入 `tests/` 目录按模块管理

## 运行测试

```bash
# 运行所有测试
uv run pytest

# 运行单元测试
uv run pytest tests/unit/

# 运行集成测试（需先启动数据库）
uv run pytest tests/integration/
```
