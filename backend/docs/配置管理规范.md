# 配置管理规范

### 文件约定

| 文件 | Git | 说明 |
|------|-----|------|
| `.env` | ✅ | 生产基线，所有键有默认值；敏感值须 `ENC(...)` |
| `.env.{APP_ENV}` | ✅（`.env.local` 除外） | 环境覆盖，只写与基线的差异 |
| `.env.local` | ❌ | 本地私有覆盖（`APP_ENV=local`） |
| `.env.test` | ✅ | 测试覆盖（`APP_ENV=test`） |

层叠顺序：`.env` → `.env.{APP_ENV}` → 运行时环境变量，后者覆盖前者，未指定键继承。缺失的覆盖文件静默跳过。

- 生产部署不设 `APP_ENV` → 只读 `.env`
- 本地开发设 `APP_ENV=local` → `.env` + `.env.local`（本地应含 `DATABASE__AUTO_MIGRATE=true`）
- 测试环境设 `APP_ENV=test` → `.env` + `.env.test`（环境配置覆盖，**不是** pytest 测试规则）

`.env.local` 由开发者从 `.env` 复制后修改：`cp .env .env.local`，只改自己机器不同的部分。`setup.sh` 生成项目时会自动写出一份并默认打开自动迁移。

实现：`app.core.config.resolve_env_files()` / `get_settings()`；与根目录 `migrate.py` 共用同一套层叠规则。不再使用 `ENV_FILE` / `.env.dev`。

### 嵌套键约定

使用 `__` 双下划线作为嵌套分隔（pydantic-settings 标准 `env_nested_delimiter`）。Docker Compose 用单下划线（如 `APP_NAME`、`APP_PORT`），两者可共存。

生产基线 `.env` 中中间件主机名为 Docker 服务名（`postgres` / `redis` / `minio`），与 Java `application.yml` 对齐；本地由 `.env.local` 覆盖为 `localhost`（`setup.sh` 生成时已写好）。全栈根 compose 会 `env_file` 注入本文件，故容器内无需再 COPY `.env`。

### 密文管理（强制）

**敏感值禁止明文提交。** 必须先用加密脚本打成 `ENC(密文)`，再写入 `.env` 并提交：

```bash
DATABASE__URL=postgresql://app:ENC(gAAAAAB...)@host/db
REDIS__URL=redis://:ENC(gAAAAAB...)@localhost:6379/0
```

| 项 | 规则 |
|----|------|
| `.env` | ✅ 可进 git（内容须为密文敏感值） |
| `.env.local` | ❌ 本机私有覆盖 |
| `CONFIG_KEY` | ❌ 永不提交，仅环境变量 / 密码管理器 |

```bash
# 脚手架仓库 scripts/secret.py（Fernet）
python scripts/secret.py generate              # 管理员生成 CONFIG_KEY
python scripts/secret.py encrypt "明文"         # → ENC(密文)
python scripts/secret.py decrypt "ENC(密文)"     # → 明文
```

- 启动时 `Settings` 通过 `EncStr`（`crypto.decrypt`）自动解密，业务代码透明
- **与 Java Jasypt 密文不互通**

### 配置项前缀

| 类别 | 前缀 | 示例 |
|------|------|------|
| 应用 | `APP__` | `APP__NAME`、`APP__DEBUG`、`APP__PORT`（基线固定 8000）、`APP__JSON_CAMEL_CASE` |
| 数据库 | `DATABASE__` | `DATABASE__URL`、`DATABASE__POOL_SIZE` |
| Redis | `REDIS__` | `REDIS__URL` |
| 日志 | `LOG__` | `LOG__LEVEL`、`LOG__TYPES` |
| 认证 | `AUTH__` | `AUTH__ENABLED`、`AUTH__SSO__ISSUER` |
| MinIO | `MINIO__` | `MINIO__ENDPOINT`、`MINIO__ACCESS_KEY` |
